# 前有古人

> 从光阴长河里，把人召上来。

一个给 AI agent 用的技能：你带着真实困境来问「怎么办」，它先去古今中外找**结构相同**的前例，验明真身，再让走过来的人用自己的嘴讲给你听。

名字取自《蛊真人》里红莲魔尊的杀招「前有古人，后有来者」——召的不是人，是那个人一生中最好的那一刻。

## 它长什么样

问：「怎么平衡生活和工作」。

> 你来了。问的是「怎么平衡」。这话我听过太多次，多半是站在河边，以为水会自己分开。一千二百年前有人在洛阳问过，一百八十年前有人在苏格兰问过，九十年前有人在密歇根问过。我把他们叫上来——这回不替他们说，让他们自己讲。
>
> **白居易**：我遇上的事，说起来也不新鲜：官做到能做事的位置，也就做到随时被牵连的位置。退一步，俸禄就断；不退，人就耗成灰。我给自己找了个分司的闲差——留司官，无公事，随月有俸钱……后来我在洛阳住了近二十年，诗写得多，人也没耗干。
>
> **洪亭**：我核过。分司是唐制里真有的格子，不是他自己编的。证据：中——史实清楚，可「因为清净，所以长寿高产」这层因果，我说不死。今天还成立吗：⚠️ 唐代有现成的格子，你那儿没有，得自己造。
>
> ——洪亭退场。下面我用自己的话说。

红莲魔尊（本名洪亭）只负责开场、召人、点评、验真；古人各用自己的口气讲自己的难处与解法；最后的共性、动作、验收，由 agent 本来的身份用平常话说。

## 安装

dsh（DeepSeek Harness）的技能就是一个目录，放进任一扫描根即可：

- 用户级：`~/.dsh/skills/`（Windows 是 `%USERPROFILE%\.dsh\skills\`）—— 对你所有项目可用
- 项目级：`.dsh/skills/` —— 随仓库提交，全队共用

技能本体只有 markdown，**Linux / macOS / Windows 通用**，没有平台相关命令依赖。

**Linux / macOS**

```bash
git clone https://github.com/BFOX98256594/qian-you-gu-ren ~/.dsh/skills/qian-you-gu-ren
# 或下载解压后在本目录跑：
./install.sh
```

**Windows（PowerShell）**

```powershell
git clone https://github.com/BFOX98256594/qian-you-gu-ren "$env:USERPROFILE\.dsh\skills\qian-you-gu-ren"
# 或下载解压后在本目录跑：
.\install.ps1
```

也可以直接手动拷贝：把 `SKILL.md` 和 `references/` 放进 `<技能根>/qian-you-gu-ren/` 即可。

新开一个会话，技能列表里出现 `qian-you-gu-ren` 就装好了。

## 什么时候触发

直接描述困境即可，不必提「历史」两个字：

- 「我这店回头客很少，怎么办」
- 「团队里老人总挤走新人」
- 「三十岁想转行，家里反对」
- 「做产品没人用，是不是方向错了」

也可以直接点名：「用前有古人看看」「历史上有没有人遇到过」。

不适用：纯事实查询、代码报错、只要一步操作步骤的场景——那时候直接答更快。

## 它怎么干活

1. **压成一句「处境式」**——剥掉行业外壳，留下结构。奶茶店复购低 = 陌生人凭什么第二次掏钱。结构相同，古人才召得上来。
2. **下河检索**——6–10 次，中英各半，四类角度：中文史料、外文先例、跨域类比、反例。
3. **验明正身**——四关：源头（两个独立来源）、年代、性质（史实／演义／传说／后世附会）、效果（因果还是时运）。最后标证据强度：强／中／弱。
4. **选 2–4 个上场**——要求代表性、成功、可迁移、能开口；至少一个来自你完全不熟的领域。
5. **反例关**——找一个同样做法的失败者，让失败者自己讲话。
6. **交卷**——洪亭开场与验真，古人自述，最后 agent 用本来的身份给动作与验收。

## 三条硬规矩

- **不编来源，也不编台词**。核不出就写「未能核实」；古人没有原话，就不给他造金句。
- **不替古人讲他的难处**。每人上场第一句必须是他自己的「我遇上的事是……」。
- **不写万能道理**。「坚持」「专注」「抓住风口」不是共性，是废话；共性必须可反证。
